Простое приложение - проект netbeans, ранее собиралось на ant, теперь перенес на maven. Используется для поиска поля и таблицы в бд firebird 2.5 где хранятся известные пользователю данные. Например по известному сохраненному в бд значению даты, найти в какой таблице и в какой записи это значение хранится.
