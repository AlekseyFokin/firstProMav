**Описание**

Простое приложение - проект netbeans, ранее собиралось на ant, теперь перенес на maven. Используется для поиска поля и таблицы в бд firebird 2.5 где хранятся известные пользователю данные. Например по известному сохраненному в бд значению даты, найти в какой таблице и в какой записи это значение хранится. 

**Инструкция по сборке**

Шаг 1: На корневой странице этого репозитория ([https://github.com/AlekseyFokin/YandexMap-KudaGo]) на середине страницы раскройте выпадающие меню на зеленой кнопке с надписью "<> Code" и скачайте исхлдные файлы с помощью кнопки Download ZIP.

Шаг 2: Распакуйте полученные файлы в заранее созданную вами директорию для проекта.

Шаг 3: Откройте IDE Netbeans, затем откройте распакованный проект в Netbeans.

Шаг 4: Запустите Build Project для сборки проекта.

Шаг 5: Запустите Run Project для запуска приложения.
